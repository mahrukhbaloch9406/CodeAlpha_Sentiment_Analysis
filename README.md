# CodeAlpha Sentiment Analysis

**Intern: Mahrukh Baloch | BSIT MNSUAM | AI Internship Task 3**

## Description
AI tool that detects sentiment (Positive/Negative/Neutral) of any text using keyword-based NLP logic. Built fully on mobile using Pydroid 3.

## Features
- Detects Positive, Negative, Neutral
- Works offline, no API
- Handles user input in real time
- Easy to extend word list

## How to Run
1. Open Pydroid 3
2. Run sentiment.py
3. Type sentences like "I love CodeAlpha" or "This is bad"

## Tech
Python 3, NLP Basics, Keyword Matching
